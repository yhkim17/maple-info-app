# 캐릭터 스케줄러 API 타 사용자 연동 및 로그인(NEXON Open ID) 구현 가능성 분석

- **일자**: 2026-11-13
- **작업자**: AI (Antigravity) & 사용자

## 1. 요청/목표 (goal)
- `/scheduler/character-state` 엔드포인트는 API 키 발급 계정의 캐릭터만 조회 가능한 정책이 적용되어 있음.
- 타 사용자가 서비스에 접속하여 본인의 캐릭터 스케줄러 정보를 조회하기 위해, "로그인하여 인증 정보를 받아와 스케줄러 조회가 가능한지"에 대한 기술적 실현 가능성 및 대안 분석.

## 2. 계획 (plan)
1. **넥슨 Open API 인증 구조 분석**:
   - `x-nxopen-api-key` 기반 인증과 `scheduler/character-state`의 권한 검증 방식 파악.
   - 넥슨 공식 "게임 데이터 활용 로그인 (NEXON Open ID)"의 제공 범위 및 신청 요건 검토.
2. **타 사용자 지원을 위한 현실적 구현 방안 도출**:
   - 방안 1: 브라우저 로컬 스토리지(`localStorage`) 기반 유저 API Key 입력 방식.
   - 방안 2: 넥슨 공식 파트너스 신청 및 NEXON Open ID 연동.
   - 방안 3: 자체 로그인(OAuth/DB) + 유저별 API Key 관리.
3. **현재 프로젝트(`maple-info-app`) 아키텍처 관점 권장안 도출**:
   - 프론트엔드(`src/api/index.ts`) 인터셉터 개선 방향 및 사용자 친화적 UI 플로우 설계.

## 3. 실행 내역 (execution)
- **넥슨 Open API 정책 조사**:
  - NEXON Open ID는 외부 서비스에서 넥슨 계정 기반 OAuth 로그인을 통해 게임 데이터를 연동할 수 있도록 지원하지만, 현재 **메이플스토리 공식 파트너스 및 승인된 프렌즈 제작자**로 한정되어 있어 일반 개인 프로젝트는 즉시 사용 불가.
- **아키텍처 대안 수립**:
  - `localStorage`에 유저의 API Key를 저장하고, `api.interceptors.request`에서 동적으로 우선 적용하는 방안 수립.

## 4. 에러/트러블슈팅 (errors)
- **해당 사항 없음** (기술 질의 및 아키텍처 분석 작업).
- 이전 트러블슈팅(`2026-10-10-0019`)과 연계하여 `OPENAPI00004` 권한 오류를 일반 사용자 입장에서 해결할 수 있는 방법론 정리.

## 5. 검증 (validation)
- 메이플스토리 서드파티 웹사이트(오픈소스 숙제 시트, 메이플 트래커 등)의 실제 구현 패턴 비교 및 실현 가능성 검증 완료.
